# 场景：普通对话

## 示例 1：疑问句

**用户输入**（中文）：
> 你觉得这个方案怎么样？

**Enfirst Bridge 流程**：
1. 语种检测：zh → 触发桥
2. 场景判定：dialog
3. 直线翻译锚点：`what do you think of this plan?`
4. 主推理（基于英语锚点）：模型用英语理解"询问对方对某方案的评价"
5. 输出（按 `<response_language>` 用中文）：
   > 这个方案整体不错，主要有三点可以考虑……

## 示例 2：命令句

**用户输入**：
> 帮我看看这段代码有没有问题

**锚点**：`help me check if this code has problems`

## 示例 3：感叹句

**用户输入**：
> 太好了，就这么办

**锚点**：`great, let's do it this way`

## 关键点

- 翻译保留语气（疑问/命令/感叹）
- 翻译结果对用户透明，用户看到的是中文输出
- 模型用英语锚点思考，减少内部对齐开销
